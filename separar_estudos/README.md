# Separar estudos DICOM

Este script lê uma pasta com arquivos DICOM, mostra as séries encontradas e permite copiar, ignorar ou separar cada série em um novo estudo.

## Como usar no Windows

1. Instale o Python 3.8 ou mais recente.
2. Execute `instalar.bat` uma vez para instalar o necessário.
3. Execute `executar.bat`.
4. Informe a pasta de origem dos arquivos DICOM e uma pasta de destino nova ou vazia.
5. Escolha o que fazer com cada série e digite `SEPARAR` para confirmar.

O script não altera os arquivos originais e não anonimiza os dados do paciente.
